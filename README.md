# Zepto SQL Data Analysis

## About the Project

This project focuses on analyzing Zepto product data using SQL.

The dataset contains information about products, categories, prices, discounts, 
availability, quantity, and product weight.

## Tools Used

- PostgreSQL
- SQL
- pgAdmin

## Key Analysis

- Product pricing analysis
- Discount analysis
- Product availability
- Category-wise analysis
- Inventory analysis
- Weight-based product categorization

## Dataset

The dataset was obtained from Kaggle and used for educational and portfolio purposes.

## SQL Queries

All SQL queries used for the analysis are available in `zepto_analysis.sql`.
